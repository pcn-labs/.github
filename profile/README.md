# Hello from PCN!

We've spent decades deep in DNS, DHCP, and IP address management, and along the way we've relied on a lot of great open source software. Now we'd like to give something back, so we're sharing some of our own tools here.

## The fine print (the friendly version)

Everything here is free to use under the license in each repository. It's
provided **as-is, without warranty or official support**. We use these tools
ourselves and maintain them in good faith, but we can't promise fixes or
response times for the open source community.

Need guaranteed support, custom features, or help running this in production?
Don't panic, that's what we do for a living. [Get in touch](https://pcn-inc.com).

## Getting involved

- **Found a bug?** Open an issue. We read them, even if we can't fix and release everything immediately.
- **Want to contribute?** Pull requests are welcome. Check each repo's CONTRIBUTING guide first.
- **Security issue?** Please don't post it publicly. Email security@pcn-inc.com.

Thanks for stopping by, and thanks for all the fish.
