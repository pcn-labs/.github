# Contributing to PCN Open Source

Thanks for your interest in contributing! We've benefited from the open source community for a long time, and we're glad to have you help make these tools better.

This guide applies to all PCN repositories unless a repository has its own CONTRIBUTING file, in which case that one takes priority.

## Before you start

These projects are maintained by a small team alongside our day jobs. We read everything, but we can't promise fast responses or that every contribution will be merged. Please don't take a slow reply or a "no" personally.

For anything bigger than a small fix, **please open an issue first** to discuss what you'd like to change. It saves everyone time if we agree on the approach before you write the code.

## Reporting bugs

Open an issue in the relevant repository and include:

- What you expected to happen, and what actually happened
- Steps to reproduce the problem
- The version you're using, plus your OS and environment details
- Any relevant logs or error messages (with sensitive data removed)

Please search existing issues first in case someone has already reported it.

**Found a security vulnerability?** Don't open a public issue. See [SECURITY.md](SECURITY.md) instead.

## Suggesting features

Feature ideas are welcome. Open an issue describing the problem you're trying to solve, not just the solution you have in mind. That helps us understand the need and find the approach that fits best.

## Submitting a pull request

1. Fork the repository and create a branch from the default branch.
2. Make your changes, following the existing code style and conventions in that repository.
3. Add or update tests where it makes sense.
4. Update any documentation affected by your change.
5. Make sure everything builds and the tests pass.
6. Open a pull request with a clear description of what you changed and why. Link the related issue if there is one.

Keep pull requests focused. One fix or feature per PR is much easier to review than several bundled together.

## Licensing

By submitting a contribution, you agree that it will be licensed under the same license as the repository you're contributing to, and that you have the right to submit it under that license.

## Be kind

We want this to be a welcoming place for everyone. Be respectful, assume good intent, and remember there's a person on the other side of every comment.

## Need more than community help?

If you need guaranteed support, custom features, or help running these tools in production, [get in touch with PCN](https://pcn-inc.com).

Thanks for contributing.
